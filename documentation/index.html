1. Introduction

Welcome to the Avenoir Couture Boutique HTML template. This is a premium, fully responsive static front-end template geared towards clothing boutiques, service consultation agencies, and luxury fashion brands.

It has been developed with **Tailwind CSS**, clean semantic HTML5, and vanilla ES6 JavaScript to ensure simple customization by end developers or integration into CMS platforms.

3. Tailwind Customization

The template utilizes Tailwind CSS. The Tailwind configuration is defined inline inside the `head` tags of each page for easy editing. You can adjust colors and fonts like so:

tailwind.config = { theme: { extend: { colors: { luxury: { accent: '#YOUR_HEX_COLOR', accentHover: '#YOUR_HOVER_HEX' } } } } }

4. Managing Products

To add, edit, or delete items in the boutique catalog, open assets/js/products.js. The database is represented by a simple JavaScript object array:

{ id: 1, name: "Product Name", price: 120.00, salePrice: 90.00, // Optional rating: 4.8, category: "men", // men or women subCategory: "shirts", // shirts, pants, outerwear, shoes, dresses sizes: ["S", "M", "L"], colors: [ { name: "White", hex: "#FFFFFF" } ], images: [ "assets/images/products/men/shirt-1.jpg", "assets/images/products/men/shirt-2.jpg" ] }

5. Theme & RTL Modes

The template supports light/dark themes and LTR/RTL layouts out of the box.

  • Dark Theme: Managed by adding the class `dark` to the `html` tag. Persistent values are cached in `localStorage` under `color-theme`.
  • RTL Alignment: Toggle alignment by adding `dir="rtl"` to the `html` tag. Custom RTL rules can be declared in `assets/css/rtl.css`.
